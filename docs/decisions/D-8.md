# D-8: Removed files go to an admin-restorable Trash

Status: Accepted (Explore gate, 2026-10-26)

## Decision
Removing a file or folder sends it to a Trash view built from git history. A repo admin can restore it with its history.

## Why
Stakeholder, on remove: "admin can restore". Git already keeps every version.

## Consequences
Whether "delete" is the same or a permanent purge, and whether users restore their own files, is still open (explore.md question 6).
