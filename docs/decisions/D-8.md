# D-8: Removed files go to an admin-restorable Trash

Status: Accepted (Explore gate, 2026-10-26)

## Decision
Removing a file or folder sends it to a Trash view built from git history. Only a repo admin (GitHub admin or maintain) can restore it, with its history.

## Why
Stakeholder, on remove: "admin can restore". Git already keeps every version.

## Consequences
Users cannot restore their own removed files (stakeholder: "only admin can restore files"). Whether "delete" also goes to Trash is still open (design.md S-15.1).
