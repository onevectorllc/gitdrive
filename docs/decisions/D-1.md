# D-1: GitHub repos are the storage

Status: Accepted (Explore gate, 2026-10-26)

## Decision
Each drive is a private GitHub repo. v1 supports GitHub only.

## Why
No server to run; accounts, teams, permissions and audit come from GitHub. Stakeholder: "github repo".

## Consequences
Permissions are per repo, not per folder. The engine talks to a generic HTTPS git remote so other hosts can be added later.
