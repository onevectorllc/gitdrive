# D-4: Sync model: local clone, batched commits, fetch-replay-retry

Status: Accepted (Explore gate, 2026-10-26)

## Decision
Each drive is a full local clone. Saves are batched about 5 s into one commit. A rejected push triggers fetch, replay and retry. Same-file conflicts produce a conflicted copy.

## Why
No git errors shown to users; nothing lost on conflict.

## Consequences
Needs load testing with simulated users. Mobile will need on-demand fetching later.
