# D-5: Sign-in through a GitHub App with device flow

Status: Accepted (Explore gate, 2026-10-26)

## Decision
Users sign in through a GitHub App using the device flow. Tokens live only in the macOS Keychain.

## Why
Fine-grained, per-repo permissions instead of a broad OAuth scope; no token pasting.

## Consequences
An org admin must install the GitHub App on the repos used as drives.
