# D-7: Scope boundaries for v1

Status: Accepted (Explore gate, 2026-10-26)

## Decision
Git LFS (AC-9) and file locking (AC-11) move to v1.1. Server backup is out of scope. v1 caps file size (AC-9a: warn above 25 MB, refuse over 50 MB).

## Why
Stakeholder: "keep LFS in backlog for v1.1"; backup "not in scope".

## Consequences
The repo grows with each edit of a binary file until v1.1 brings LFS.
