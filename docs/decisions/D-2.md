# D-2: Shared core engine in Rust on libgit2

Status: Accepted (Explore gate, 2026-10-26)

## Decision
The core engine is a Rust crate on git2-rs (libgit2), exposed to Swift (and later Kotlin) through UniFFI.

## Why
One engine for Mac, iOS, iPad and Android; libgit2 is mature for clone, fetch and push over HTTPS.

## Consequences
No Apple-only dependencies in the core (AC-12). The git layer sits behind our own trait so gitoxide could replace libgit2.
