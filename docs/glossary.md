# Glossary

- **LFS (Git Large File Storage):** git add-on that stores large files outside the repo and keeps only small pointer files in git. Files download only when opened.
- **File Provider:** macOS extension API that makes a cloud drive appear in the Finder sidebar (used by Google Drive and Dropbox). Planned for v1.1.
- **Conflicted copy:** the losing version of a same-file conflict, saved next to the file so no work is lost.
